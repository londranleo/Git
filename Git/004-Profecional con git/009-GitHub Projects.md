# GitHub Projects

**GitHub Projects** es una herramienta de GitHub para **organizar y gestionar el trabajo de un proyecto**.

Permite convertir las tareas del proyecto en elementos organizados dentro de un tablero. Estos elementos pueden estar relacionados con **Issues y Pull Requests**.

Por ejemplo, puedes tener un tablero con:

```
Pendiente        En progreso       Terminado
─────────        ───────────       ─────────
Login            Registro          Documentación
Base de datos    API usuarios      Tests
```

Cuando empiezas una tarea, la mueves a **En progreso**. Cuando terminas y la integras, pasa a **Terminado**.

La diferencia con Issues es:

```
Issues
→ registran problemas, tareas o propuestas.

Projects
→ organizan y visualizan esas tareas para gestionar el trabajo.
```

Projects resulta especialmente útil cuando un proyecto tiene **muchas tareas y varias personas trabajando en ellas**, porque permite ver qué está pendiente, qué se está haciendo y qué ya se terminó.
