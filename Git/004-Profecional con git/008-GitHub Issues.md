# GitHub Issues

**GitHub Issues** es una herramienta de GitHub para **registrar, organizar y hacer seguimiento de tareas, problemas o propuestas relacionadas con un proyecto**.

Una Issue puede representar, por ejemplo:

- un error que hay que solucionar;
- una funcionalidad que se quiere desarrollar;
- una mejora del proyecto;
- una tarea pendiente.

La idea es que las tareas del proyecto no dependan únicamente de conversaciones o notas externas. Cada problema o tarea puede quedar registrado y tener su propio seguimiento.

Una Issue puede contener una descripción, comentarios, etiquetas y personas asignadas.

Por ejemplo:

```
Issue #15
"El login permite introducir una contraseña vacía"
```

El desarrollador puede trabajar en una rama para solucionar ese problema y posteriormente crear una Pull Request con la solución.

La relación puede ser:

```
Issue
  ↓
Trabajo en una rama
  ↓
Commits
  ↓
Pull Request
  ↓
Revisión
  ↓
Integración
```

**GitHub Issues no forma parte de Git como sistema de control de versiones**. Es una herramienta de GitHub que ayuda a gestionar el trabajo alrededor del código.
