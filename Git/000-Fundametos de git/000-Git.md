**Git es un sistema de control de versiones.**

Su función es permitirte **registrar los cambios que haces en un proyecto y conservar su historial**.

Por ejemplo, imagina que estás desarrollando una aplicación Java:

```
MiAplicacion/
├── Main.java
├── Usuario.java
└── Conexion.java
```

Durante el desarrollo vas haciendo cambios. Git permite guardar estados importantes del proyecto:

```
Versión 1 → Proyecto inicial
Versión 2 → Sistema de usuarios
Versión 3 → Conexión con MySQL
Versión 4 → Sistema de login
```

Cada uno de esos estados puede quedar registrado mediante un **commit**.

La ventaja es que no dependes de copiar carpetas manualmente para conservar versiones. Git mantiene el historial y permite consultar qué cambió, cuándo cambió y recuperar estados anteriores cuando sea necesario.

### Git y GitHub no son lo mismo

Esto es importante desde el principio:

**Git** es la herramienta que utilizas en tu ordenador para controlar las versiones.

**GitHub** es una plataforma donde puedes almacenar repositorios Git remotamente y trabajar con otras personas.

La relación sería:

```
Tu proyecto
    ↓
   Git
    ↓
Repositorio local
    ↓
  GitHub
    ↓
Repositorio remoto
```
